Try running the following command to see if the RTL-SDR hardware can even play an AM radio station:
	rtl_fm -E direct2 -M am -f 1530k -s 24k - | aplay -r 24000 -f S16_LE

If that doesn't work try:
	rtl_fm -M am -f 1530k -s 24k - | aplay -r 24000 -f S16_LE

If that doesn't work, then the current hardware cannot pick up AM.
Try using a different antenna. If the other antennas do not work, the RTL is faulty.
